# BEST KOTA Website

A modern, responsive website for **BEST KOTA** – Big Taste, Real Satisfaction.

## How to put this website on GitHub Pages (Free)

### Step 1: Create a new GitHub repository
1. Go to [github.com](https://github.com) and log in
2. Click the **+** → **New repository**
3. Name it something like `best-kota` or `best-kota-website`
4. Make it **Public**
5. Click **Create repository**

### Step 2: Upload the files
1. On the new repository page, click **uploading an existing file**
2. Drag and drop these 3 files:
   - `index.html`
   - `styles.css`
   - `README.md`
3. Click **Commit changes**

### Step 3: Turn on GitHub Pages
1. Go to the repository **Settings** tab
2. On the left menu, click **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose branch: **main** and folder: **/ (root)**
5. Click **Save**

### Step 4: Your website is live!
After 1–2 minutes your site will be available at:

```
https://your-username.github.io/best-kota/
```

(Replace `your-username` and `best-kota` with your actual GitHub username and repository name)

## Customisation tips

- **WhatsApp number**: Search for `27711234567` in `index.html` and replace with your real number (keep the country code without +)
- **Address / Email / Phone**: Update in the footer section of `index.html`
- **Images**: Replace the Unsplash image links with your own kota photos
- **Prices & Menu items**: Edit the menu cards in `index.html`
